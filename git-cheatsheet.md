# Git Command Cheat Sheet

### 1. Check Git Version

```bash
git --version
```

### 2. Configure Git Username

```bash
git config --global user.name "sumanadk123"
```

### 3. Configure Git Email

```bash
git config --global user.email "adksuman35@gmail.com"
```

### 4. View Git Configuration

```bash
git config --list
```

### 5. Create a New Repository

```bash
git init
```

### 6. Clone a Repository

```bash
git clone https://github.com/sumanadk123/dti412-lab01.git
```

### 7. Check Repository Status

```bash
git status
```

### 8. Add Files to Staging Area

```bash
git add .
```

### 9. Commit Changes

```bash
git commit -m "Your commit message"
```

### 10. View Commit History

```bash
git log --oneline
```

### 11. Push Changes to GitHub

```bash
git push origin main
```

### 12. Pull Latest Changes from GitHub

```bash
git pull origin main
```

### 13. View Branches

```bash
git branch
```

### 14. Create and Switch to a New Branch

```bash
git checkout -b branch-name
```

### 15. Switch to Another Branch

```bash
git switch main
```

### 16. Rename Current Branch

```bash
git branch -m main
```
